Manufacturers often hand you a thin spec sheet ("see catalog for details") plus a separate PDF catalog with the actual descriptions, features, and applications. This step reads the PDF catalog, matches each row of your spec sheet to its catalog content by item number, and produces a clean merged dataset in the format the rest of ListingIQ expects (Part Number / Brand / Product Type / Key Specs / Additional Info 1-3) — which then feeds Tabs 2-5 exactly like a normal upload.

Only have one of the two files? This tab still helps. Spec sheet but no catalog: skip Step 1 and go straight to Step 2 - it'll still flatten a messy multi-section sheet and clean it up, just without catalog enrichment. Catalog but no spec sheet: upload just the PDF, run Step 1, then use "Build Rows From Catalog Only" instead of Step 2. Already have a clean, single-table sheet? Skip this tab entirely and upload straight into the box at the top of the page - Product Name/Highlights/etc. work exactly as before.
